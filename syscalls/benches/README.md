# Regenerate

```
syscalls/benches/update_bench_results.py
```

The script detects the ark-bn254 version pulled in by `solana-bn254` (from `Cargo.lock`), runs `cargo bench -p solana-syscalls`, saves raw output to `syscalls/benches/results/ark-{ver}.txt` and parsed upper bounds to `ark-{ver}.json`, and rewrites the four tables below.

Re-render the README from existing `results/*.json` without rerunning benches:

```
syscalls/benches/update_bench_results.py --no-run
```
